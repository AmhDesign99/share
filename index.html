Kenapa hemat kuota?

Pembukaan GitHub Pages dan koneksi signaling tetap membutuhkan sedikit internet. Setelah WebRTC terhubung langsung, file dikirim lewat DataChannel antar-perangkat. Pada jaringan lokal yang memungkinkan jalur langsung, server signaling tidak menjadi jalur data file.
Catatan: jika jaringan memaksa relay TURN, trafik dapat keluar melalui internet. Konfigurasi aplikasi ini tidak memasang TURN, sehingga fokusnya koneksi langsung/LAN.
