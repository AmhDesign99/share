Berbagi folder langsung antar perangkat.

Buka halaman yang sama di dua perangkat. Pairing menggunakan QR Code, lalu file dikirim melalui WebRTC DataChannel. GitHub hanya menjadi tempat halaman aplikasinya.

Belum terhubung. Mulai dari Buat Sesi di perangkat pengirim.

1. Pengirim

Buat sesi, lalu tampilkan QR Code. Penerima tinggal scan.

Setelah penerima membuat QR jawaban, tekan tombol di bawah untuk memindai.

2. Penerima

Scan QR dari pengirim. Setelah itu tampilkan QR jawaban untuk pengirim.

3. Shared Folder

Pilih satu folder atau banyak file. Struktur folder disimpan dari webkitRelativePath bila tersedia.

OFFLINE
Tap untuk memilih fileDesktop: tarik file atau folder ke sini

4. File diterima

File yang masuk muncul di sini. Pada browser yang mendukung File System Access API, kamu bisa memilih folder tujuan agar subfolder dibuat otomatis.
